# 📈 Crypto-Exchange Simulator by KET_KAT

Консольный симулятор биржи и торговли активами с элементами прокачки репутации и покупки недвижимости.

## 🚀 Особенности проекта
* **Динамический рынок**: Цены на нефть, биткоин, золото и платину меняются каждый раз, когда игрок ложится спать.
* **Стабильные активы**: Алмазы имеют фиксированную цену для сохранения капитала.
* **Система сохранений**: Весь прогресс (деньги, репутация, день, купленные активы и недвижимость) автоматически сохраняется в `save.json` при выходе.
* **Пассивный доход**: Покупка недвижимости приносит ежедневную прибыль, но требует высокого уровня репутации.
* **Благотворительность**: Игрок может жертвовать деньги в различные фонды для прокачки репутации.

## Технологии
* Python 3.12.9
* Встроенные модули: `json`, `random`, `os`, `time`

## 📦 Запуск игры
Для запуска игры скачайте файл `crypto_exchange.py` и запустите его на компьютере с установленным Python:
```bash
python crypto_exchange.py
```
